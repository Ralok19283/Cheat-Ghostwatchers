GHOST WATCHERS CHEAT MENU  v2.1
===============================

INSTALL
  1. Right-click the zip -> "Extract All" (use Windows, not 7-Zip/WinRAR).
  2. Double-click "Install Trainer.bat".
     -> finds the game, closes it, installs the menu, starts the game again
        and shows OK when the menu is running.
  If Windows shows "Windows protected your PC": click "More info" -> "Run anyway".
  After that the menu loads automatically every time you start the game.

IN GAME
  Press F9 to open/close the cheat menu (the mouse gets freed so you can click).

  LOCAL tab (works always, also when someone else hosts)
    Revive          Revive everyone / yourself, God mode for you or everyone (instant revive)
    Speed           Movement speed 1x - 3x
    Fly / noclip    WASD, Space up, Ctrl down, Shift fast
    Fullbright      Light up the whole map, brightness slider
    Teleport        To the ghost, to the start/van, to a teammate
    ESP             Ghost, players, revive orbs, ectoplasm, items through walls
                    (orbs and ectoplasm only exist during a run)
    Ghost info      Ghost type, age and mood
    Slot machine    Pick which prize the lobby slot machine always hits

  HOST / SERVER tab
    Online lobbies are run by the game's server, so nobody is ever "host" there.
    Works online too:
      Auto-identify   Enters the correct ghost answer at the terminal
      Weakening       Skip the next weakening step (online only for "say a phrase",
                      "take ghost photo" and "identify" - the rest you do yourself)
      Bonus tasks     Skip the next bonus task (needs a photo/video camera or
                      advanced thermometer somewhere in the level)
    Single-player only:
      Freeze ghost, ghost can't hunt/attack, sanity fill/keep full, infinite items

UPDATE
  Double-click "Update Trainer.bat" (the menu shows when a new version is out).
  Installing also always grabs the newest version automatically.

UNINSTALL
  Double-click "Uninstall Trainer.bat".

EXTRA: SAVE EDITOR (folder "Save Editor")
  Double-click "Run Save Editor.bat":
  100,000,000 money, level 112, all skins/bracelets/drones, all lobby decorations,
  all capsule upgrades, all ghosts on Diamond statue. Old save is backed up in the game folder
  (SavesDir_backup_<date>). If Steam asks about a cloud save conflict: choose LOCAL.

If a Steam "verify game files" or a game update removes the menu, run "Install Trainer.bat" again.
